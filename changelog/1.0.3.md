# 1.0.3 · 一句中文，紧跟一句英文

日期：2026-10-07。

- 浮窗从“整段原文在上、整段译文在下”改成按句对照：一句中文，紧跟对应的一句英文；下一句中文、下一句英文接着排下来。
- 翻译范围仍然只限你正在输入的这一句，但一句里再按**逗号和顿号**细分。写“明天要去见客户，还得带上合同，然后送他去机场。”会得到三组对照，而不是一整块。
- 逗号后面跟着「不过、但是、所以、and、but」这类连词时不断开——那半句是完整语义，切开就碎了。
- **分号不断**。没有标点的口语算一整句，不会被切碎。
- 组内两行靠得近，组与组之间稍微松一点。靠间距区分，不加分割线、卡片和说明文字。
- 长句照常换行，不截断、不缩小到难读，也不会出现横向滚动条。切出多少行都不设上限，靠展开后的滚动兜底。展开和收起用同一份内容。
- 输入英文时同样逐句对照：中文在上、原来的英文在下，原句不会被改写。
- 拖选、双击选词、跨句选择都还能用。复制按钮只拿走完整译文，不含原文。
- 悬停查词会先认出你停在哪一句，用这一句的上下文来解释；拖选的时候暂停查词，词卡图钉照旧。

## 怎么做的

- 一次翻译请求里就把整段和每个子句的编号一起交给模型，让它照着编号回译文。不会一个子句一次联网，也不会为了排版多问模型一次：等待时间和调用次数跟以前一样。
- 模型没把某个编号还回来时，屏幕上**只显示对上了的那几组**，不编造也不回退成一整句。缺的那半句不会凭空出现。
- 0.5 秒停顿触发和语音上屏后触发都保持原样。0.5 秒只是“什么时候发出去”，不代表网络已经回话。

## 还没做好什么

- 这次只把中英互译的对照做稳。其他语言的译文方向、查词和语音要连在一起设计，留到后面的阶段。
- 新增的平台仍然没有全部用真实账户跑过，音色和额度得用各自的 Key 才有意义。沿用之前记录的验证范围。
- 真实桌面上的观感、听感和滚动手感还需要你本人过一遍；自动检查通过不等于你已经验收。

## 检查了什么

- 基础与接口检查 296 项通过。新增的检查覆盖：逗号与顿号切分、分号不断、中英文连词不断开、英文缩写与小数不被误切；一次请求就带回全部子句；缺编号时只保留对上的那几组；编号重复、格式非法、截断和取消的降级；乱序返回按编号还原而不是按位置错配。
- 浮窗、对照渲染、三套皮肤、萌宠和液面 423 项通过。包含：每组两行、组内距离小于组间距离、跨组选择、整段复制只含译文、仅译文模式、查词取本组上下文、展开收起复用同一份结果、长段可滚动且不横向滚动、切三套皮肤不丢句子。
- 另外把浮窗用内置演示数据渲染成图片逐张看过：收起、展开、仅译文、长段、逗号级细分、连词不断和两套主题皮肤都符合预期（见 artifacts，仅本机核对用，不进发布包）。
- 检查中发现并修掉一个真实缺陷：编号重复的返回原本**根本没有被识别**（判断循环漏了写入），重复编号会被当成正常结果照常显示。现在会退回整段。
- 没有调用真实 API，不消耗额度，也没有动你的 Key 和配置。

## 用户操作负担

- 常规使用：和以前一样——你照常打字或语音输入，停半秒后自动出对照。新增填写 0 项、额外确认 0 次、外部切换 0 次，不需要你手动拆句，也不需要多点一次展开才能看到对照。
- 想听的时候点一次朗读，顺序和屏幕上的译文一致。想看更多就展开或直接滚。
- 出错的时候：保留已经打好的字和还能看的结果，可以直接重试或改配置，不用重打一段、不用重填 Key。窗口也不会被上一轮的旧结果盖住。

以上是按一条正常路径的实测操作数，不是估算；按钮总数不等于完成任务的操作数。
