# 1.0.0 · 首个公开版本

日期：2026-10-05。开源仓库名称：yu-ban。

本地开发曾使用 1.9.1 等编号；公开发行从 1.0.0 重新开始。这是版本编号重新整理，不是把已有功能退回早期版本。

## 这次改了什么

- 翻译从 DeepSeek、千问扩展为 9 家：另加 OpenAI、Kimi、智谱、豆包 / 火山方舟、硅基流动、Gemini、Claude。
- 云端语音从千问扩展为 5 家：另加 OpenAI、硅基流动、MiniMax、ElevenLabs。Windows 系统语音继续保留。
- 设置中的 i 信息跟着所选平台变化，可以打开或复制各家的官方平台、接口文档链接。
- 模型、接口和音色可以在信息弹窗里的“模型与接口”调整，不再要求用户编辑配置文件。
- 各个平台分别记住 Key 和型号。换回千问时，原有工作空间地址和音色能保留。
- 修复试听结束后的界面更新可能跑到错误线程的问题。
- 托盘加入便携版换路径后的注册备用方式；当前受限命令环境的托盘检查仍未通过，不能据此宣布所有桌面环境都验证成功。
- 重写 README，用普通用户看得懂的方式说明怎么用，以及哪些地方还不能自动翻译。
- 可执行文件、清单、文档统一标为公开版本 1.0.0。

## 检查到哪一步

新增平台没有 Key，所以本轮不做真实付费调用，也不假装它们全部实测成功。请求结构、鉴权、返回解析、失败提示、Key 隔离和切回配置用离线模拟接口检查。

当前自动检查：214 项基础与接口检查通过；334 项包含浮窗、三套皮肤、液面、萌宠、朗读状态及本机固定缓存试听的检查通过。托盘专用检查在当前命令环境失败，直接桌面验收启动遇到工具授权超时，保留为待验收项。

这次没有解决微信直接读取输入框。复制原文、手动粘贴翻译仍是备用方式；也没有把查词词库变成无遗漏词典。

个人 Key、配置、缓存音频、历史安装备份和桌面快捷方式不进入开源包。
