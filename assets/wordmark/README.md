# 语伴字标

使用 ZCOOL KuaiLe（站酷快乐体）的「语伴」两个字，按 104 单位字距转成 WPF 矢量轮廓。显示尺寸 180 × 81 DIP。不是新字体，也不修改原字体文件。

字体来源：https://github.com/google/fonts/tree/main/ofl/zcoolkuaile

Copyright 2018 The ZCOOL KuaiLe Project Authors。字体采用 SIL Open Font License 1.1，完整许可见 OFL.txt。

运行 generate.ps1 可重新生成 yuban.path。构建只嵌入轮廓，运行时不需要安装字体，也不需要联网下载。字体原件和生成脚本保留供维护使用。
