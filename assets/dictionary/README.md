# 本地词典

## 英文词典（查英文词）

来源：[skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)，MIT 许可，原许可见 LICENSE-ECDICT.txt。

2026-10-04 获取官方 master 的 ecdict.csv。1.4 曾只保留带考试/词频等标记的 58,226 条词条，导致 scrollable、clickable 等已有释义的词被漏掉。1.4.1 取消这一筛选，保留 399,213 条有中文释义的英文单词（可含连字符或撇号，长度不超过 45）。保留原数据音标、中文词义和词形变化，加载时将屈折词形关联到原形。多词短语不在此词表中，需结合本句解释。

此词典由语伴单独接入，不是从青简输入法词库抽取。扩大收录不等于所有新词、专名都能查到；不把派生词直接猜成某个原词释义，也不自动触发收费模型查询。

words.jsonl.gz 是生成的内嵌资源，无运行时网络下载；每行依次为单词、音标、中文释义、词形字段。音标沿用原数据，不自动标成美音或英音；词典未提供音标时不编造。数据可能有遗漏和旧式音标记号。

查询时会拆出词性（n. / v. / adj. 等）单独显示，因为查词的人最想先看到读音和词性。拆不出来就留空，不编造。

重建：使用 Python 运行 `prepare.py 原始ecdict.csv words.jsonl.gz`。Python 仅用于重建，应用运行不依赖它。

本次使用的原 CSV SHA-256：`1A6947E04785DB63613A92E14903CDAE7954F7E84860B10E68E5C7CBB3F9C3CF`。原始下载文件留在开发机 artifacts/，不把不完整的 CSV 片段当作完整数据发布。

## 中文词典（查中文词，给学中文的人用）

来源：[CC-CEDICT](https://cc-cedict.org/)，由 MDBG 发布，**CC BY-SA 4.0** 许可。

选用它的原因：本项目需要"中文词 → 拼音 + 英文释义"这一方向，而 ECDICT 只有英译中。两者互补不冲突——查英文词走 ECDICT，查中文词走 CEDICT。

2026-10-10 获取 MDBG 发布的 `cedict_1_0_ts_utf-8_mdbg.txt.gz`（125,244 条词条）。生成时把数字声调转成带声调符号的拼音（`ni3 hao3` → `nǐ hǎo`），因为使用者看的是拼音本身而不是数字；繁体写法额外补成指向简体条目的别名，因此资源内共 198,234 条可查条目。

chinese.jsonl.gz 与英文词典同构，每行依次为词、拼音、英文释义、词形字段，因此复用同一套读取与查询代码。查中文词按原样匹配，不做大小写折叠。

重建：使用 Python 运行 `prepare-cedict.py 原始cedict.txt.gz chinese.jsonl.gz`。
