# 语伴 · yu-ban

**打字的同时学英语，点击即听地道发音。** **———省去传统输入法手动点击翻译的步骤，让语言学习成为日常的陪伴。**

<img width="785" height="220" alt="屏幕截图 2026-10-06 113103" src="https://github.com/user-attachments/assets/8cc211ed-a330-46f7-bbf1-8ba9f8b68f8a" />

语伴是一个 Windows 桌面小工具。用户无需更换输入法 or 输入方式，它会在输入框附近显示英语译文；点一下朗读，就能听这句话怎么说。

它适合想在日常聊天、写作、搜索甚至 vibe  coding 时顺手练英语的人；也适合先用中文想清楚，再复制英文去表达的人。

## 下载与开始

1. 在 [Releases](https://github.com/chujiachen167-ui/yu-ban/releases) 下载 `yu-ban-1.0.3-windows-x64.zip`，解压整个文件夹。
2. 双击 `EnglishCompanion.exe`。翻译默认选 DeepSeek，语音默认选千问，分别填入自己的 API Key。
3. 点“确认”，回到输入框，照常输入。

不知道 API Key 去哪里拿，可以点击或悬停设置里的 **i**图标，打开官方平台，也能复制链接。需要更换模型或音色时，点信息弹窗里的“模型与接口”；千问语音点“配置千问语音”，填写工作空间 ID 即可自动生成地址，获取 ID 的官方指引也在弹窗里。

需要 Windows 10/11 的 64 位系统和 .NET Framework 4.8。不用替换输入法，不用安装浏览器插件。再次双击程序即可打开设置；托盘右键可以暂停或退出。不会开机自启。

## 能做什么

- **逐句对照**：普通打字停顿约半秒后自动发起翻译；Alt 语音输入结束（以豆包输入法为例）、文字上屏后直接请求。译文出现的速度还取决于网络和模型。一句中文紧跟对应的一句英文；长句里再按逗号、顿号细分；输入英文时中文在上、原英文在下。
- **朗读**：点击朗读，再点停止。播放时有跳动音量条；同一句重复播放复用最近的音频。
- **双语模式 or 仅译文**：在设置里切换。
- **复制功能**：可以拖选复制，也可以用复制按钮拿走完整译文，然后自己粘贴回聊天框。
- **查单词**：展开浮窗，悬停单词查看音标和释义；图钉可以固定词卡。拖选时暂停查词，双击照常选词。句中解释和单词朗读需要点击后才调用模型。
- **换皮肤**：官方默认、大肥鱼、小奶蛙。默认设置页有半透明液面，两套主题的浮窗带动态角色。

千问 Audio 3.1 的英语朗读还支持“现状／自然会话／清晰伴读”与几种英语音色试听。这项偏好暂时只适用于这个型号，其他服务商使用各自的音色配置。

## 可以接哪些平台

| 用途 | 已加入的服务商 |
| --- | --- |
| 翻译 | DeepSeek、千问、OpenAI、Kimi、智谱、豆包 / 火山方舟、硅基流动、Gemini、Claude |
| 云端朗读 | 千问、OpenAI、硅基流动、MiniMax、ElevenLabs |
| 本地朗读 | Windows 系统语音，无需 Key，需安装相应语言音色 |

翻译和语音可以选不同平台。每家的 Key、模型和接口分别保存，切换时不会把另一家的 Key 带过去。语伴本身不收取使用费，模型调用费用由你选择的平台计算。

**新增平台暂未全部做真实调用。** 目前完成了离线请求、返回解析和错误处理检查；DeepSeek 与千问是前期本机使用过的组合。账户额度、地域、套餐权限和声音效果仍需要相应平台的 Key 才能验证。模型名称会变化，可在“模型与接口”改成平台当前支持的型号。详细默认值和验证范围见 [服务商说明](docs/providers.md)。

## 哪些地方还有限制

自动翻译需要输入框提供 Windows 的文字读取接口。豆包、搜狗输入法配合可读取的输入框已经在前期本机体验中使用过，不能保证所有软件都支持。

**微信等部分自绘输入框目前无法直接读取。** 可以复制原文，按 `Ctrl + Shift + F7` 打开粘贴翻译，再复制译文回去。我们欢迎社区一起改善这类兼容问题。

浮窗不会替你发送消息，也不会自动把英文写回输入框。一次翻译最多 1800 字，朗读最多 600 字符。本地词典可能漏收新词和专有名词。

## 你的数据

Key 用 Windows 当前用户加密，保存在本机 `%LOCALAPPDATA%\EnglishCompanion\settings.json`，不会包含在源码或下载包中。翻译发送当前需要翻译的一句话给所选平台；朗读、句中解释点击后才调用。不会自动读取剪贴板，不上传截图、整份文档或聊天记录。

原文、译文和最近一次音频只放在内存里，退出后清空。朗读偏好的固定示例音频会保存在本机，方便重复试听。

## 来源与许可

想法与早期实践受到 [青简输入法](https://github.com/qingjian-team/qingjian) 的启发。语伴随后做成独立桌面工具，不需要修改青简、豆包或搜狗的文件，与这些产品没有隶属关系。

作者一开始看到青简输入法这个项目的时候，感觉这真是个天才般的好主意，于是萌生了对其进行优化，并且上传优化版本的念头。但实际上手使用之后，发现它更偏向于以背单词为主，而用户需要在设置里面选用云服务才能进行整句翻译。于是作者结合自身学习英语的经历、习惯。开发出了这一款以先看到英文译文，并且听见地道发音为主，而单词查询、背诵为辅的软件———语伴。不仅仅是因为作者本身不喜欢背单词，我觉得这太死板了。而且作者认为更好的语言学习方式就是多听多读，把自己放入那个语言环境中去。甚至理想的状态就是：脑海中的一个概念，它能很自然地产出中文的释义与英文的释义这两种不同的版本。所以语言的运用其实是概念与想法先行，而不是单纯地对两种不同语言之间的对应单词进行单纯的翻译。
